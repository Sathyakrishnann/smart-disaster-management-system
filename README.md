# Smart Disaster Response Coordination Platform

AI Powered Smart Disaster Response Coordination Platform

## Overview

An AI-powered disaster management platform designed to improve emergency response, resource allocation, volunteer coordination, and citizen safety during natural disasters.

## Technologies

- Node.js
- Express.js
- MongoDB
- Python
- OpenCV
- Scikit-learn
- Leaflet.js
- OpenStreetMap
